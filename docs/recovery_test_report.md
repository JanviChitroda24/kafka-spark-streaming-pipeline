## How Exactly-Once Works

Three mechanisms work together:

1. **Kafka producer `acks='all'`** — message confirmed on all in-sync replicas before the producer continues
2. **Spark checkpoints** — store processed Kafka offsets per query. On restart, Structured Streaming resumes from the last committed offset.
3. **Delta Lake ACID writes** — crash mid-write leaves no committed partial batch in the transaction log. Restart reprocesses that batch cleanly.

SIGKILL is the worst case — no graceful shutdown, no buffer flush. If exactly-once holds under SIGKILL, it holds under softer failure modes (SIGINT, OOM, node loss with checkpoint on durable storage).
