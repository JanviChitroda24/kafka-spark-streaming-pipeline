## 3. Why This Matters

- **Time travel** lets you debug bad data by querying previous versions, or roll back a corrupted table.
- **Schema enforcement** prevents bugs in the streaming processor from silently writing garbage data.
- Both features come with Delta Lake — use `.format('delta')` instead of `.format('parquet')`.
